OG-XOX

The SP-404MKII, cut back to the samplers it grew from. OG-XOX adds OG-404, OG-303 and OG-202 modes that switch off every button the original SP-404, SP-303 or SP-202 didn't have, next to SP-404 mode, the MK2 as it ships. Hold EXIT and turn VALUE to switch.

Install Help

Install

OG-XOXfor SP-404MKII system 5.52
  1. Download the SP-404MKII System Program 5.52 from Roland. OG-XOX works on 5.52 only, and Roland's files don't come with it.
  2. Choose the download below, either the .zip as it comes or the SP404MKII_APP1.bin inside it. It stays on this computer: the page patches it right here.

What the patch changes

    Put it on the SP

    1. Back up your SD card.
    2. Copy the downloaded SP404MKII_APP1.bin to the root of the SP's SD card (formatted on the SP).
    3. Hold SHIFT and switch the SP on. When it shows "UPDATE SURE?", press VALUE.
    4. Wait for "UPDATE COMPLETE!" and don't switch off before then. Switch off, take the file off the card, and switch on: the OG-XOX splash appears for three seconds.

    To go back to stock, do the same with Roland's own SP404MKII_APP1.bin from the 5.52 download. Your projects and samples aren't touched either way.

    Before you install

    OG-XOX is new, and has been tried on one SP-404MKII. It changes the SP's system program, and you install it at your own risk. Updating is the same procedure Roland uses, so reinstalling Roland's 5.52 file is always the way back. If something misbehaves, go back to stock.

    Switching modes

    • Hold EXIT: a menu lists SP-404, OG-404, OG-303 and OG-202, the current mode inverted.
    • Turn VALUE (EXIT still held): up or down the list. It switches straight away, and stops at either end.
    • Click VALUE (EXIT still held): the next mode, wrapping from OG-202 back to SP-404.
    • Let go of EXIT: the menu closes. Pads, effects and EXIT itself work as usual while it's held.

    The SP remembers the mode when you switch it off. After the splash, a popup names the mode if it's an OG mode.

    The modes

    Pads, the five effect buttons and MFX work in every mode. In the OG modes, buttons the original didn't have do nothing and stay dark, and so does anything pressed while one of them is held (which takes out the MK2's SHIFT shortcuts). VALUE clicks do nothing on their own.

    ModeButtons that work
    SP-404All of them: the stock MK2.
    OG-404Banks, HOLD, EXT SRC, SUB PAD, GATE, LOOP, REVERSE, REC, RESAMPLE, DEL, PTN SELECT, REMAIN, EXIT
    OG-303As OG-404, without SUB PAD and REMAIN
    OG-202As OG-303, without EXT SRC, RESAMPLE and PTN SELECT. No pattern sequencer: switching to OG-202 leaves pattern mode.

    Good to know

    • The SP's menus and settings are untouched, including UTILITY > SYSTEM, which still shows 5.52.
    • Some of the SP's own dialogs ask for a VALUE press (deleting, resampling settings). In an OG mode VALUE clicks do nothing, so switch to SP-404 mode to confirm them, or press EXIT to back out.
    • The effects, screens and readouts are the MK2's own in every mode for now.

    If the page refuses your file

    It patches Roland's 5.52 SP404MKII_APP1.bin exactly, checked by its fingerprint, so an older or newer version, an APP0 file, or a file that's already patched won't do. Download 5.52 from Roland again and choose that.
