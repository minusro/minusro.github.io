GBM8

A Game Boy and Game Boy Color emulator for the Dirtywave M8. Copy your games to the M8's SD card, pick one, and play it on the M8's keys, with save states, the cartridge clock, and the colours a Game Boy Color gives older games.

Install by hand

This browser can't install firmware on the M8. In Chrome or Edge on a computer, this page installs GBM8 with one click. Here, install it by hand with TyUploader, the way Dirtywave's own updates go:

  1. Download the file for your M8:
    • Looking up the latest release…
  2. Install TyTools (on a Mac, move it to the Applications folder).
  3. Connect the M8 to the computer with a USB data cable, switch it on, and quit anything else that uses it: M8C, the headless display, a serial monitor.
  4. Open TyUploader (not TyCommander), check the M8 is selected in its list, click Upload and choose the file.

To go back to the M8's own firmware, download it from Dirtywave's downloads page and install the .hex for your model the same way.

On Linux, install PJRC's udev rules for Teensy first (the M8 is built around a Teensy), then unplug and replug the M8.

Install

  1. Connect the M8 to this computer with a USB data cable, then switch it on.
  2. Quit anything else that uses the M8 over USB: M8C, the headless display, Teensy Loader, TyCommander, a serial monitor.
  3. Click Install, and choose the M8 when the browser asks. The page restarts it into its loader and installs.

GBM8 replaces the M8's firmware while it's installed: to make music again, use Restore below. No games come with it: copy your own .gb and .gbc files to the SD card, in any folder (GBM8's USB drive mode lets you do that over the cable). The Model:02 build hasn't been tried on a Model:02 yet.

Go back to the M8's own firmware

Downloads the latest firmware from Dirtywave's downloads page and installs the file for your M8's model. It comes straight from Dirtywave to your browser; this site doesn't host it. Installing it means you agree to Dirtywave's licence (EULA.txt in their download).

If something goes wrong

    
It's safe to try again

    
The M8's loader sits on its own chip, and installing never overwrites it. If an install stops partway, the M8 waits in its loader: click Upload to try again. After reloading the page, click Install, close the browser's pop-up, then click Upload. Installing doesn't touch the SD card, so your songs, games and saves stay put, whichever firmware you install.

    
The M8 isn't in the browser's pop-up

    
Check the M8 is switched on, and try another cable (some only charge). If the M8 is already in its loader (after a stopped install, for instance), it doesn't show there: close the pop-up and click Upload.

    
An Upload button appears

    
The M8 is waiting in its loader: click Upload and choose it when the browser asks. Cancel goes back to the start.

    
Upload's pop-up is empty

    
The M8 didn't restart into its loader. Click Cancel, check nothing else is using the M8 (see the next point), then click Install again.

    
"Couldn't open the M8's USB port"

    
Another app has it. Quit M8C, Teensy Loader, TyCommander and any serial monitor (such as the Arduino IDE's), then try again.

    
"Nothing was written"

    
The .hex file you chose is built for the other M8 model. Your M8 is unchanged: choose the file for your model.

    
The screen stays dark after "Done"

    
Switch the M8 off and on.

Games on the card

    
Copy .gb and .gbc files anywhere on the SD card, in any folders. GBM8 opens on the card's folders and shows only folders and Game Boy files. To copy games without taking the card out, choose USB drive mode in the settings or the in-game menu: the card shows up on the computer as a drive until you eject it there or press any key on the M8.


    
Playing

    
    
      
  • ▲ ▼ ◀ ▶: the D-pad.
    • 
      
  • EDIT: A. OPT: B.
    • 
      
  • PLAY: START. SHIFT: SELECT.
    • 
      
  • Power key tap, or SHIFT + PLAY held a second: the menu.
    • 
      
  • Power key held 1.5 s: save where you are and switch off.
    • 
    


    
The games list

    
    
      
  • ▲ ▼: move (hold to scroll). ◀ ▶: a page at a time.
    • 
      
  • EDIT: open a folder or start a game. OPT: up a folder.
    • 
      
  • PLAY or a power key tap: the settings (volume, brightness, picture, USB drive mode, switch off).
    • 
    


    
The in-game menu

    
▲ ▼ selects, ◀ ▶ changes a value, EDIT chooses, and OPT, PLAY or a power key tap goes back to the game.

    
    
      
  • Save state / Load state: three slots per game; ◀ ▶ picks the slot.
    • 
      
  • Palette (original Game Boy games): the original Game Boy's green unless you pick another. AUTO colours the game the way a Game Boy Color does, picked by its title. Also Pocket grey and the twelve start-up palettes of a Game Boy Color. Remembered per game.
    • 
      
  • Picture (Model:01): 1:1 (each Game Boy pixel one screen pixel: small and sharp), 1.5X, FIT (the full height, the right shape) or FULL (stretched). The Model:02 shows exactly 2×.
    • 
      
  • Volume, Brightness.
    • 
      
  • Reset game: press EDIT twice.
    • 
      
  • USB drive mode and Quit to games.
    • 
    


    
Saves

    
    
      
  • Quitting or switching off saves where you are. The next time you start that game, GBM8 asks whether to continue from there or start from the beginning.
    • 
      
  • A game's own saves go in a .sav file next to it, in the format other emulators use, so they carry over both ways. The cartridge clock of games that have one (MBC3) keeps running while the M8 is off.
    • 
      
  • Save states and settings go in the card's GBM8 folder.
    • 
    


    
What runs

    
Game Boy and Game Boy Color games up to 8 MB, on cartridges with no MBC, MBC1, MBC2, MBC3 or MBC5. Not the Pocket Camera, the link cable, or MBC7, HuC1, HuC3 and MMM01 cartridges. A few games that depend on exact memory timing may glitch.
